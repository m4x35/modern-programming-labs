Опис предметної області
Сервіс доставки призначений для оформлення та супроводу замовлень на доставку посилок. Клієнт створює замовлення та додає до нього одну або декілька посилок. До замовлення може бути призначений кур'єр, після чого доставка може бути розпочата та завершена. Система підтримує стандартний та експрес-способи доставки та контролює основні правила роботи із замовленнями.
